# Somon Rent Bot

Личный телеграм-бот: следит за новыми объявлениями об аренде квартир в Душанбе
на [somon.tj](https://somon.tj) и мгновенно присылает те, что подходят под твои фильтры.

## Как это работает

Сайт somon.tj построен на Next.js и рендерит данные объявлений в виде JSON внутри
RSC-чанков (`self.__next_f.push(...)`) прямо в HTML. Бот ищет этот JSON и парсит
объявления из него — это надёжнее, чем парсить вёрстку (у которой нет стабильных
CSS-классов, только Tailwind-утилиты). Если сайт изменит структуру и JSON исчезнет,
бот сам переключится в упрощённый fallback-режим (парсинг ссылок `/adv/{id}_{slug}/`)
и один раз в час предупредит тебя, что пора чинить `scraper/parser.py`.

Новизна объявления определяется по числовому ID из ссылки (`/adv/17005957_.../` →
`17005957`), а не по тексту вроде «18 минут назад» — он неточный и локализованный.

## Установка за 5 шагов

### 1. Получи токен бота

Напиши [@BotFather](https://t.me/BotFather) в Telegram → `/newbot` → следуй инструкциям.
Получишь токен вида `123456:ABC-DEF...`.

### 2. Узнай свой chat_id

Напиши [@userinfobot](https://t.me/userinfobot) — он пришлёт твой числовой ID.

### 3. Настрой `.env`

```bash
cp .env.example .env
nano .env
```

Обязательно заполни `BOT_TOKEN` и `ADMIN_CHAT_ID`. Остальные фильтры можно оставить
по умолчанию и поменять потом прямо из бота командами.

### 4. Запусти

Через Docker (проще всего):

```bash
docker compose up -d
docker compose logs -f
```

Через systemd (если хочешь без Docker):

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
sudo cp somon-bot.service /etc/systemd/system/
sudo nano /etc/systemd/system/somon-bot.service   # поправь User= и пути, если нужно
sudo systemctl daemon-reload
sudo systemctl enable --now somon-bot
journalctl -u somon-bot -f
```

### 5. Проверь в Telegram

Напиши боту `/start`, затем `/test` — должен показать 3 реальные карточки с ценой,
комнатами, площадью и этажом. Если всё ок — просто жди уведомлений.

## Команды бота

| Команда | Действие |
|---|---|
| `/start` | приветствие + статус |
| `/status` | работает/пауза, интервал, последняя проверка, режим парсинга, последняя ошибка |
| `/filters` | показать все фильтры (с кнопками быстрого переключения) |
| `/set price_max 6000` | установить любой фильтр |
| `/unset area_min` | сбросить фильтр |
| `/rooms 1 2 3` | быстрая установка комнатности |
| `/district add Сино` / `del` / `clear` | управление районами |
| `/block <author_url или id объявления>` | заблокировать автора |
| `/pause [минуты]` | пауза (без аргумента — бессрочно) |
| `/resume` | продолжить |
| `/last [N]` | последние N подходящих объявлений (по умолчанию 5) |
| `/check` | проверить прямо сейчас |
| `/test` | диагностика парсера: 3 карточки без фильтров |
| `/interval 45` | сменить интервал опроса (не меньше 20 сек) |
| `/stats` | статистика за 7 дней |
| `/export` | выгрузить CSV подходящих объявлений |

## Если парсер сломался

Если `/test` возвращает пустой список или `/status` показывает "режим парсинга:
fallback" дольше нескольких часов — вёрстка или структура данных сайта изменилась.
Бот при этом не падает и продолжает работать в упрощённом режиме (без цены и автора),
но лучше почини парсер. Скорми Claude Code:

```
Парсер сломался — /test возвращает пустой список (или работает в fallback-режиме).
Скачай свежую страницу https://somon.tj/nedvizhimost/arenda-kvartir/dushanbe/
в tests/fixtures/, сравни со старой фикстурой, найди что изменилось,
почини scraper/parser.py и обнови тесты.
```

Дампы HTML при ошибках парсинга автоматически сохраняются в `debug/` (последние 5).

## Как обновлять фикстуры

Фикстуры в `tests/fixtures/` — это сохранённые реальные страницы somon.tj.
Сайт встраивает в них живые сторонние ключи (Google Maps, Mapbox — для своих
карт), поэтому сырую страницу коммитить нельзя: GitHub push protection
заблокирует пуш, а если проскочит — в репозитории окажется чужой рабочий ключ.

Порядок при обновлении:

1. **Скачал** свежую страницу:
   ```bash
   curl -s -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/128.0.0.0 Safari/537.36" \
     -H "Accept-Language: ru-RU,ru;q=0.9,tg;q=0.8" \
     -H "Referer: https://somon.tj/" \
     -o tests/fixtures/listing_page.html \
     "https://somon.tj/nedvizhimost/arenda-kvartir/dushanbe/"
   ```
2. **Прогнал** `python scripts/sanitize_fixtures.py` — вычищает известные
   паттерны ключей (Mapbox `pk.ey`/`sk.ey`, Google `AIzaSy...`), заменяя каждое
   совпадение на строку `x` **той же длины**. Это критично: обычная замена
   другой длины сдвигает байтовые смещения JSON внутри RSC-чанка
   (`self.__next_f.push(...)`), парсер не может его распарсить и молча
   уходит в fallback-режим — именно так фикстуры один раз уже ломались.
3. Если после обновления фикстуры новые ID/цены/районы не совпадают со
   старыми тестовыми ожиданиями — обнови конкретные значения в
   `tests/test_parser.py` под новые реальные данные.
4. **Прогнал** `pytest` — должно быть всё зелёное, включая
   `tests/test_fixtures_clean.py` (отдельная проверка, что секретов не
   осталось — она же используется в CI/pre-commit через
   `python scripts/sanitize_fixtures.py --check`).
5. **Закоммитил.**

## Ограничения (сознательные, по ТЗ)

- Бот личный, рассчитан на одного пользователя (`ADMIN_CHAT_ID`).
- Интервал опроса не может быть меньше 20 секунд.
- Телефон продавца скрыт на somon.tj за кликом — бот его не вытаскивает, только даёт ссылку.
- `exclude_last_floor` не реализован по-настоящему: общая этажность дома отсутствует
  в данных ленты объявлений (только этаж конкретной квартиры). Поле есть в фильтрах
  для совместимости, но реально не отсекает объявления.
- Настройки паузы (`/pause`) не переживают перезапуск бота — после рестарта бот
  всегда стартует в активном режиме. Это осознанный выбор: безопаснее продолжить
  мониторинг, чем молча остаться на паузе после сбоя.

## Разработка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/pytest
.venv/bin/ruff check .
```

## Структура проекта

```
somon-rent-bot/
├── bot/            # aiogram: команды, клавиатуры, очередь уведомлений, конфиг
├── scraper/        # HTTP-клиент, парсер (JSON + fallback), нормализация текста
├── core/           # SQLite, фильтры, цикл опроса
├── tests/          # pytest + фикстуры реальных страниц somon.tj
├── debug/          # автодампы HTML при сбоях парсера
└── data/           # SQLite база (bot.db)
```
